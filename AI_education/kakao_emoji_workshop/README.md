# 🎨 카카오톡 16종 이모티콘 공방 (Kakao Emoji Workshop)

내 얼굴 사진 1장을 바탕으로 AI 카툰 캐릭터를 만들고, 대학생 리얼 일상 16종 테마의 **카카오톡 공식 규격(360x360 PNG) 이모티콘 팩**으로 자동 가공·배포하는 바이브코딩 프로젝트입니다.

---

## 📁 프로젝트 구조

```
kakao_emoji_workshop/
├── generate_pack.py         # 4x4 시트 자동 분할, 외곽선 및 자막 합성, ZIP 압축 스크립트
├── index.html               # 카카오톡 모바일 채팅 시뮬레이터 & 16종 미리보기 웹 뷰어
├── output_emoticons/        # 가공된 360x360 규격의 16종 PNG 이모티콘 저장 폴더
├── 대학생_16종_이모티콘팩.zip # 16종 이모티콘 압축 배포 파일
└── README.md                # 실습 가이드 및 안내서
```

---

## 🚀 빠른 시작

### 1. 필수 라이브러리 설치
```bash
pip install pillow
```

### 2. 실행 방법

#### [1단계] AI로 4x4 캐릭터 시트 이미지 준비
* Midjourney, DALL-E 3, Stable Diffusion 등의 이미지 생성 AI에 본인 사진과 함께 아래 프롬프트를 입력하여 **4x4 그리드 캐릭터 시트(1장)**를 생성합니다.
* 생성된 이미지를 본 프로젝트 폴더에 `sheet.png` (또는 `sheet.jpg`) 이름으로 저장합니다.

> **💡 추천 AI 생성 프롬프트 예시:**
> *"이 사진 속 인물의 헤어스타일, 안경, 얼굴 특징을 유지하면서 카카오톡 이모티콘에 어울리는 귀여운 2D 웹툰 3등신 캐릭터로 그려줘. 16가지 서로 다른 감정(인사, 눈물, 멘붕, 환호, 달리기, 밥먹기 등)을 표현한 4x4 그리드 캐릭터 시트 한 장으로 만들어줘."*

#### [2단계] 파이썬 자동 가공 & ZIP 패키징 실행
```bash
# 폴더 내 sheet.png가 있으면 자동으로 인식하여 실행됩니다.
python generate_pack.py

# 또는 특정 이미지 경로를 직접 지정하여 실행할 수도 있습니다.
python generate_pack.py 내_캐릭터_시트.png
```

* **동작 내용**:
  1. 4x4 그리드를 정확하게 16개(360x360px)로 자동 슬라이싱
  2. 카카오톡 감성 볼드 폰트 + 흰색 외곽선 스트로크 자막 자동 합성
  3. `output_emoticons/` 폴더에 `01_hello.png` ~ `16_escape.png` 순서로 저장
  4. `대학생_16종_이모티콘팩.zip`으로 자동 압축

#### [3단계] 웹 뷰어 & 카카오톡 시뮬레이터 확인
* `index.html` 파일을 브라우저에서 더블클릭하여 엽니다.
* **갤러리 카드 클릭 시**: 우측 카카오톡 모바일 폰 시뮬레이터 화면에 해당 이모티콘이 실시간으로 전송되는 인터랙션을 체험할 수 있습니다.
* **`📥 ZIP 팩 다운로드`** 버튼을 누르면 완성된 이모티콘 팩을 즉시 다운로드할 수 있습니다.

## 📱 실제 카카오톡에 등록해서 쓰는 방법

1. **PC 카카오톡** 실행 후 아무 채팅방이나 들어갑니다.
2. 입력창 하단의 **[이모티콘(웃는 얼굴)]** 아이콘 클릭
3. 상단 탭 맨 오른쪽 **[+] 또는 [스티커 관리]** 메뉴 선택
4. `output_emoticons/` 폴더 안의 투명 PNG 파일들을 등록하면, **실제 단톡방에서 내 얼굴 캐릭터 스티커를 전송**할 수 있습니다!
