공용 PC에서 이전 사용자의 GitHub 계정 정보를 지우거나 계정을 전환하려면 운영체제별 자격 증명 저장소에서 `github.com` 항목을 삭제해야 합니다. 윈도우와 맥 각각의 초기화 절차는 다음과 같습니다.

---

### 1. Windows에서 삭제하기 (자격 증명 관리자)

윈도우는 **자격 증명 관리자**에 GitHub 인증 정보를 보관합니다.

1. **자격 증명 관리자 실행:** 1분.
작업 표시줄의 **검색(돋보기) 아이콘**을 클릭한 뒤 `자격 증명 관리자`를 입력하고 실행합니다.
*Verification:* 제어판의 '자격 증명 관리자' 창이 화면에 열립니다.


2. **Windows 자격 증명 탭 선택:** 30초.
상단 메뉴에서 두 번째 아이콘인 **Windows 자격 증명**을 클릭합니다.
*Verification:* 아래쪽에 '일반 자격 증명' 목록이 표시됩니다.


3. **GitHub 항목 찾기 및 제거:** 1분.
**일반 자격 증명** 목록에서 `git:[https://github.com](https://github.com)` 항목을 찾아 클릭한 뒤 **제거**를 누르고 확인 창에서 **예**를 선택합니다. (관련 항목이 여러 개라면 모두 제거합니다.)
*Verification:* 일반 자격 증명 목록에서 `git:[https://github.com](https://github.com)` 항목이 완전히 사라집니다.


---

### 2. Mac에서 삭제하기 (키체인 접근)

맥은 **키체인 접근(Keychain Access)** 앱을 통해 GitHub 로그인 정보를 관리합니다.

1. **키체인 접근 실행:** 1분.
키보드에서 `Command(⌘) + Space`를 눌러 Spotlight 검색을 연 뒤 `키체인 접근`을 입력하고 실행합니다. (암호 또는 Touch ID 인증 창이 뜨면 비밀번호를 입력합니다.)
*Verification:* '키체인 접근' 창이 열리고 왼쪽 사이드바에 '로그인' 키체인이 보입니다.


2. **GitHub 인증 항목 검색:** 30초.
우측 상단 검색창에 `github.com`을 입력합니다.
*Verification:* 목록에 `github.com` 인터넷 암호 또는 응용 프로그램 암호 항목이 필터링되어 나타납니다.


3. **항목 삭제:** 1분.
검색된 `github.com` 항목을 마우스 우클릭(또는 두 손가락 클릭)한 뒤 **'github.com' 삭제**를 누르고 확인 창에서 **삭제**를 선택합니다.
*Verification:* 검색 결과 목록에서 `github.com` 항목이 사라집니다.


---

### 💡 초기화 확인 및 추가 점검 사항

* **초기화 성공 확인:** 터미널(또는 Git Bash)에서 `git push`를 다시 실행했을 때 새로운 로그인 창(또는 토큰 입력 프롬프트)이 뜨면 정상적으로 초기화된 것입니다.
* **전역 Git 사용자 이름/이메일 초기화:** 자격 증명과 별개로 기존 사용자의 이름과 이메일(`git config`)도 남아 있을 수 있으므로, 수업 시작 전 아래 명령어로 기존 설정을 지워두는 것이 좋습니다.
```bash
git config --global --unset user.name
git config --global --unset user.email

```


* **웹 브라우저 로그아웃:** 브라우저 기반 인증(`Authorize git-ecosystem`)을 사용하는 경우, 크롬이나 엣지 등 웹 브라우저에서 [github.com](https://github.com)에 접속해 기존 계정이 로그아웃되어 있는지도 함께 확인하세요.
