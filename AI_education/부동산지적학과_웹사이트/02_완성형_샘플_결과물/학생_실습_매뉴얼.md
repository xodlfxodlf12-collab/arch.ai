## 1. 준비 운동: 내 컴퓨터에서 바로 열어보기

1. 압축을 푼 `01_학생_실습용_템플릿` 폴더로 이동합니다.
2. **`index.html`** 파일을 마우스로 **더블 클릭**합니다.
3. Chrome(크롬) 또는 Edge(엣지) 브라우저가 열리며 웹사이트가 즉시 나타납니다.
4. **체크 포인트:**
   - 화면 중앙의 **QGIS 공간분석 뷰어**에서 우측 레이어 버튼을 눌러 켜고 끄거나, 지도 위의 필지(`656-12` 등)를 클릭해 보세요.
   - 우측 하단의 **🗺️ 동그란 챗봇 버튼**을 눌러 추천 질문 버튼을 클릭해 보세요.

## 2. 폴더 지도: 파일들이 하는 일 한눈에 보기

복잡해 보이지만 우리가 수정할 핵심 파일은 딱 3개입니다:

| 파일명 | 역할 | 비유 |
| :--- | :--- | :--- |
| **`index.html`** | 웹사이트의 뼈대와 글자 내용 | 필지의 **지적도와 경계선** |
| **`style.css`** | 색상, 폰트, 여백, 반투명 효과 | QGIS의 **심볼 스타일과 레이아웃** |
| **`script.js`** | QGIS 레이어 토글, 필지 속성, 챗봇 로직 | 공간정보 **분석 엔진과 속성 테이블** |
| **`maps/`** | 본인의 QGIS 내보내기 지도(`.png`)를 넣는 곳 | **QGIS 인쇄 조판 주제도 전시실** |

> 💡 **핵심 원칙:** 코드를 직접 타이핑해서 고치려 하지 마세요! AI에게 *"어떤 파일의 어디를 이렇게 바꿔줘"*라고 말하는 것이 **바이브 코딩(Vibe Coding)**입니다.

## 3. 실습 1단계: 내 프로필과 전공 비전 입히기

웹사이트 맨 위(Hero 섹션)와 맨 아래(Footer)에 내 이름과 관심 분야를 넣습니다.

1. **`index.html`** 파일을 VS Code 또는 텍스트 에디터로 엽니다.
2. `<!-- ✏️ [학생 실습 1-1] -->`, `<!-- ✏️ [학생 실습 1-2] -->`, `<!-- ✏️ [학생 실습 1-3] -->` 주석을 찾습니다.
3. 아래 항목을 내 정보로 바꿉니다:

   * **슬로건:** 내가 추구하는 공간·부동산 비전 (예: *"데이터로 토지의 숨겨진 가치를 발견하다"*)
   * **자기소개:** 학년, 이름, 관심 분야 (지적측량, 감정평가, QGIS 입지분석, 프롭테크 등)
   * **하단 연락처(Footer):** 이메일 주소 및 링크드인/깃허브 링크

## 4. 실습 2단계: 나만의 테마 컬러(퍼스널 컬러) 바꾸기

현재 스카이 블루(`--accent: #38bdf8`)인 포인트 컬러를 내 전공 스타일에 맞는 색으로 한 번에 바꿀 수 있습니다.

1. **`style.css`** 파일을 엽니다.
2. 맨 첫 줄의 `/* ✏️ [학생 실습 2] */` 바로 아래를 봅니다:
   ```css
   :root {
       --accent: #38bdf8; /* 👈 이 색상 코드를 원하는 색으로 변경! */
   }
   ```
3. **추천 부동산·지적 컬러 팔레트:**
   * 🛰️ **QGIS / 공간정보 / 지적측량:** 스카이 블루 `#38bdf8`
   * 🌳 **국토·환경 / 공익 토지:** 에메랄드 그린 `#10b981`
   * 🏙️ **도시개발 / 프롭테크 / 투자:** 앰버 골드 `#f59e0b`
   * 📊 **빅데이터 / AI 가치평가:** 모던 바이올렛 `#a855f7`
4. 저장 후 브라우저에서 **`F5`(새로고침)**를 누르면 버튼, 테두리, 발광 효과가 모두 새 색상으로 바뀝니다!

## 5. 실습 3단계: 내 분석 프로젝트(지적·QGIS·개발) 등록하기

홈페이지 중간의 **Selected Works 갤러리 카드**와 **상세 모달 창**에 내 프로젝트를 넣습니다.

1. **`script.js`** 파일을 엽니다.
2. 상단의 `const projectsData = [ ... ];` 배열을 찾습니다.
3. 1번 프로젝트의 정보를 지난 학기에 진행했던 내 과제 정보로 교체합니다:
   ```javascript
   {
       id: 1,
       title: "서울시 빈집 활용 로컬 상권 활성화 입지분석",  // 프로젝트 제목
       category: "gis",                                   // cadastral(지적측량), valuation(가치평가/개발), gis(QGIS/빅데이터)
       year: "2025.Spring (3학년 1학기)",
       location: "서울시 용산구 해방촌 일대",
       area: "분석 대상 빈집 64개소 / 반경 500m",
       structure: "QGIS + Python(GeoPandas) + 공시지가 회귀분석",
       concept: "노후 주거지 내 빈집 분포와 청년 유동인구 데이터를 중첩하여...",
       images: [
           "내 QGIS 지도 이미지 URL 또는 로컬 경로"
       ]
   }
   ```
4. **`index.html`**의 프로젝트 카드 제목과 요약 문구도 동일하게 수정하면 완벽합니다.

## 6. 실습 4단계: 나만의 AI 도슨트 챗봇 완성하기

우측 하단의 **🗺️ 챗봇**을 나만의 포트폴리오 전문 비서로 훈련시킵니다.

### A. 기본 룰베이스 모드 (API 키 없이 100% 작동 - 수업 필수)
1. **`script.js`**의 `const scenarioResponses = [ ... ];`를 찾습니다.
2. 방문자가 자주 물어볼 키워드(`keywords`)와 답변(`answer`)을 내 프로젝트 내용으로 바꿉니다.
3. **`index.html`**에서 `<!-- ✏️ [학생 실습 4] -->` 아래의 추천 질문 버튼(`<button class="cb-chip">`) 글자도 맞춰서 바꿉니다.

### B. 실시간 AI 모드 (Google Gemini API 연동 - 선택 심화)
1. 웹사이트를 연 상태에서 챗봇 창 우측 상단의 **⚙️ 설정 버튼**을 누릅니다.
2. [Google AI Studio](https://aistudio.google.com/)에서 무료 발급받은 API Key를 붙여넣고 **[Gemini 연동 저장]**을 누릅니다.
3. 이제 추천 질문 외에 어떤 자유 질문을 던져도 AI가 내 프로젝트 데이터를 읽고 실시간으로 답변합니다!

## 7. 실습 5단계: 내 QGIS 지도 결과물(.png/.jpg) 띄워보기 (선택)

QGIS 인쇄 조판(Print Layout)에서 만든 공간분석 주제도를 내 웹페이지에 바로 올릴 수 있습니다.

1. QGIS 상단 메뉴 **`프로젝트 -> 인쇄 조판 -> 이미지로 내보내기`**를 선택해 `.png` 또는 `.jpg` 파일로 저장합니다.
2. 파일 이름을 **`qgis_map.png`**로 변경하여 **`maps/`** 폴더 안에 넣으면 사이트 실행 시 자동으로 내 지도가 표시됩니다!
3. 또는 웹 화면의 **[📁 내 QGIS 지도 업로드]** 버튼을 눌러 내 컴퓨터에 있는 QGIS 지도 이미지를 즉시 불러와 시연할 수 있습니다.

## 8. 치트키: AI에게 복사해서 던지는 프롬프트 5선

코딩이 막힐 때는 AI 채팅창에 아래 문장을 그대로 복사해서 붙여넣으세요!

1. **전체 프로필 일괄 변경:**
   > "지금 열린 `index.html`과 `script.js`에서 작성자 이름을 '박서준' 대신 '[내이름]'으로, 이메일을 '[내이메일]'로, 전공 소개를 '[내 관심 분야]'로 전부 바꿔줘."
2. **프로젝트 카드 추가 (3개 → 4개):**
   > "`index.html`의 프로젝트 카드 그리드와 `script.js`의 `projectsData`에 내 4번째 프로젝트('[프로젝트명]', 카테고리 'gis')를 하나 더 추가해줘."
3. **QGIS 뷰어 필지 속성 변경:**
   > "`script.js`의 `parcelAttributes`에서 `p1`~`p6` 필지의 지번, 지목, 면적, 공시지가를 내가 QGIS에서 분석한 '[대상 지역명]' 필지 정보로 수정해줘."
4. **모바일 화면 최적화 점검:**
   > "`style.css`에서 스마트폰 세로 화면(너비 480px 이하)일 때 QGIS 뷰어와 프로젝트 카드가 한 줄에 1개씩 예쁘게 보이도록 미디어 쿼리를 다듬어줘."
5. **로컬 QGIS 이미지 연결:**
   > "내가 `maps` 폴더에 `gis_map.png` 파일을 넣었어. `index.html`의 첫 번째 프로젝트 썸네일과 `script.js` 모달 이미지가 이 로컬 지도를 보여주도록 경로를 수정해줘."

## 9. 자주 묻는 질문 (FAQ)

* **Q. 로컬에서 `index.html`을 열었는데 `maps/qgis_map.png`가 자동으로 안 떠요!**
  * A. 파일 이름이 정확히 `qgis_map.png`인지 확인해주세요. 만약 바로 테스트하고 싶다면 웹 화면의 **[📁 내 QGIS 지도 업로드]** 버튼으로 내 컴퓨터의 `.png`/`.jpg` 파일을 직접 선택하시면 100% 즉시 표시됩니다!
* **Q. Gemini API 키를 넣었는데 깃허브에 올리면 해킹당하지 않나요?**
  * A. 이 템플릿은 API 키를 코드 파일에 저장하지 않고, 사용자의 브라우저 내부(`localStorage`)에만 임시 저장하도록 설계되어 있어 GitHub에 코드를 올려도 키가 유출되지 않습니다.
