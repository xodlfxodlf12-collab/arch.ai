# 🗺️ 02_완성형_샘플_결과물 (GEO-FOLIO Master Showcase)

본 폴더는 **부동산·지적 인터랙티브 AI 포트폴리오의 최종 완성본**입니다.  
2주차 수업 시작 시 학생들에게 *"오늘 우리가 AI와 함께 완성할 최종 목표 결과물"*로서 프로젝터 화면에 시연하거나 데모로 제공하는 기준 모델입니다.

---

## 🌟 탑재된 핵심 기능

1. **상용급 공간정보(Geospatial) 다크 테마 디자인**
   - 지적도 좌표 격자 감성의 그리드 배경, 반응형 글래스모피즘 UI
   - 프로젝트 갤러리(지적재조사 / 가치평가·개발 / QGIS·빅데이터) 및 상세 리포트 모달 팝업

2. **QGIS 인터랙티브 공간분석 & 지적 필지 뷰어**
   - 연속지적도 필지 경계, 100m 격자 밀도 히트맵, 역세권 도보권 버퍼, 국공유지 후보지 마커 레이어 ON/OFF 토글
   - 지도 위 필지 클릭 시 지목·면적·공시지가·용도지역 속성 정보 즉시 표시
   - `maps/qgis_map.png` 자동 로드 및 화면에서 즉석 QGIS 인쇄 조판 이미지(`.png/.jpg`) 업로드 지원

3. **관점별 30초 핵심 브리핑 (Audience-Tailored Briefing)**
   - 교수님/감정평가사/도시개발 실무자 평가 시각에 맞춘 4대 관점(지적측량, 가치평가, QGIS 입지, 프롭테크 툴체인) 탭 전환

4. **🤖 플로팅 AI 도슨트 챗봇 위젯 (Dual-Track 하이브리드)**
   - **기본 모드 (옵션 B: 룰베이스)**: API 키 없이도 추천 질문 칩(QGIS 지적재조사, 역세권 사업성, QGIS 입지분석, 연락처) 클릭 시 즉각 전문 해설 출력
   - **실시간 AI 모드 (옵션 A: Gemini 연동)**: 상단 ⚙️ 설정에서 Google AI Studio API 키를 입력하면 실제 LLM과 실시간 자유 대화 지원
