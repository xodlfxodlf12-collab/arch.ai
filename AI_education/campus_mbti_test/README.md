# 🎓 대학생 캠퍼스 MBTI 성향 테스트 웹앱 (Campus MBTI Test)

20대 대학생들이 가장 열광하는 스모어/푸망 스타일의 **SNS 바이럴형 심리테스트 웹앱** 프로젝트입니다.  
프로그래밍의 핵심 논리인 **[선택지 입력 ➔ 가중치 점수 누적 ➔ 조건문 판정 ➔ 시각적 결과 렌더링]** 과정을 체득합니다.

---

## 📁 프로젝트 구조

```
campus_mbti_test/
├── index.html       # [핵심] 모바일 카드 뷰 기반 감성 웹앱 (단일 HTML, 서버 불필요)
├── mbti_test.py     # [파이썬 실습] 콘솔 CLI 버전 점수 누적 및 분기 로직 실습 코드
└── README.md        # 실습 가이드 및 안내서
```

---

## 🚀 빠른 시작

### 방법 1: 웹 브라우저에서 실행 (강력 추천)
* 별도 설치나 서버 구동 없이, `index.html` 파일을 더블클릭하여 크롬 등 웹 브라우저에서 바로 실행합니다.
* 스마트폰 화면 비율(모바일 반응형)로 디자인되어 있어 PC와 모바일 모두에서 깔끔하게 동작합니다.

### 방법 2: 파이썬 콘솔 로직 실행
```bash
python mbti_test.py
```
* 터미널에서 질문에 1번/2번을 입력하며 조건문과 딕셔너리 점수 누적 알고리즘을 확인합니다.

---

## ✨ 핵심 기능 & 학습 포인트

1. **상태 관리 및 진행률(Progress Bar)**
   - 문항을 선택할 때마다 부드럽게 상단 프로그레스 바가 차오르고 다음 문항으로 자동 전환됩니다.
2. **점수 누적 알고리즘 (E/I, T/F, J/P)**
   - 답변마다 성향 스코어를 카운팅하고, 최종 합산에 따라 4~8가지 캐릭터 유형으로 자동 매핑합니다.
3. **취향 저격 결과 화면 & 바이럴**
   - 🦁 팀플 버스기사 사자, 🐆 벼락치기 치타, 🦉 과탑 부엉이, 🦥 방구석 나무늘보
   - 찰떡 단짝 vs 극상성 궁합 매칭
   - `결과 링크 복사 & 자랑하기` 버튼
