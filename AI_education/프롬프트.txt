## 1. 강의 개요

* **교육 대상**: 코딩 비전공자, 문과/예체능계열 대학생, 프로그래밍 입문자
* **핵심 목표**: 복잡한 환경 설정과 문법 암기 없이, 생성형 AI를 페어 프로그래머로 활용하여 **즉각적인 시각적 결과물(이모티콘, 지도, GUI 앱, 심리테스트 웹)**을 제작하는 경험 제공
* **수업 설계 3대 원칙**:
  1. **No Syntax, Just Logic**: 코드 타이핑 대신 기능 기획과 논리적 문제 해결에 집중
  2. **즉각적인 도파민(시각적 피드백)**: 첫 시간부터 즉각 반응하는 비주얼 프로젝트로 흥미 유발
  3. **일상 연결성 & 바이럴**: 친구들과 단톡방/SNS에 공유하고 캡처해 자랑할 수 있는 산출물 제작

## 2. 수강생 필수 훈련: 바이브코딩 가이드

### ① '3단계 프롬프트 공식' 훈련
AI에게 지시할 때는 항상 아래 3요소를 포함하도록 지도합니다.
* **역할 부여 (Role)**: *"너는 파이썬 이미지 처리 / 데이터 시각화 / 웹 프론트엔드 전문가야."*
* **핵심 기능 (Task)**: *"내가 올린 사진을 카툰 캐릭터로 변환하고 16종 이모티콘 세트로 분할해줘."*
* **제약 사항 (Constraint)**: *"별도 서버 없이 로컬에서 바로 실행되어야 하고, 파일 규격은 가로세로 360x360 투명 PNG로 해줘."*

### ② 빨간 에러 대처 3원칙
1. 에러 메시지에 당황하지 않기
2. **[내가 하려던 행동 + 터미널의 빨간색 에러 메시지 전문]**을 그대로 복사하여 AI에게 붙여넣기
3. AI가 제안한 수정 코드를 교체 적용하고 다시 실행하는 루틴 반복 체득

### [트랙 1] 생성형 AI 기반 카카오톡 '움짤' 이모티콘 공방
* **주제**: "내 얼굴 사진 한 장으로 대학생 16종 이모티콘 팩 만들기"
* **수업 목표**: 첫 시간부터 본인/친구의 얼굴을 활용한 나만의 굿즈를 완성해 최고의 몰입도와 성취감 확보
* **주요 도구**: Image-to-Image 생성 AI API (또는 오픈소스 카툰 필터) + Python Pillow(PIL)

#### 파이프라인
```
[내 얼굴/셀카 1장 업로드] 
  → 1단계: 2D 웹툰/카툰 캐릭터화 (얼굴 특징 유지)
  → 2단계: 대학생 필수 16종 감정 시트 생성 (인사, 과제 멘붕, 종강 등)
  → 3단계: 파이썬 배경 투명화 + 흰 외곽선 + 카톡 폰트 자막 합성
  → 4단계: 360x360 규격 ZIP 일괄 다운로드 & PC 카톡 등록
```

| 차시 | 강의 및 실습 내용 | 핵심 산출물 |
| :--- | :--- | :--- |
| **1차시** | **캐릭터 프롬프트 & 16종 감정 시트 생성**<br>• 사진 속 인물 특징(헤어, 안경 등)을 살린 3등신 캐릭터 프롬프팅<br>• 16종 감정 포즈 시트 일괄 생성<br>• Pillow로 16개 360x360 PNG 파일 자동 슬라이싱 저장 | 개별 분할 PNG 16장 |
| **2차시** | **스티커 가공 & GUI 패키징**<br>• 스티커 외곽선(굵은 흰색 테두리) 및 자막 폰트 자동 합성<br>• Tkinter 4x4 미리보기 창 및 ZIP 압축 다운로더 제작<br>• PC 카카오톡 '나만의 스티커' 등록 및 실전 전송 테스트 | `나만의_이모티콘팩.zip` |

#### 실습 프롬프트 가이드 (2단계 분리)
* **1단계 (AI 이미지 생성 프롬프트)**:
  > *"이 사진 속 인물의 헤어스타일, 안경, 표정 특징을 살려서 카카오톡 이모티콘용 귀여운 2D 웹툰 3등신 캐릭터로 그려줘. 대학생 일상 16가지 감정(인사, 눈물, 멘붕, 환호, 달리기, 밥먹기 등)을 표현한 4x4 그리드 시트 한 장으로 만들어줘."*
* **2단계 (파이썬 가공 & 패키징 프롬프트)**:
  > *"폴더 안의 4x4 캐릭터 시트를 파이썬 Pillow로 각각 360x360 크기 16개 PNG로 잘라줘. 각 캐릭터 하단에 카카오톡 스타일 흰색 테두리 자막('안뇽!', '살려줘...', '종강이다!!' 등)을 넣고, `대학생_16종_이모티콘팩.zip`으로 자동 압축해줘."*

### [트랙 2] 데이터 크롤링 & 전국 인터랙티브 지도 시각화
* **주제**: "스타벅스 매장 데이터 크롤링과 나만의 내비게이션 지도"
* **수업 목표**: 웹에서 실제 데이터를 긁어와 CSV로 정제하고, 브라우저 화면에 인터랙티브 지도로 시각화
* **주요 도구**: Python, Requests/BeautifulSoup, Folium / Leaflet.js
* **중요 지침 (지도 백지화 방지)**:
  * 로컬 브라우저(`file://`) 실행 시 지도가 하얗게 깨지는 문제를 원천 차단하기 위해 **`tiles='OpenStreetMap'`(무료 오픈소스 타일)**을 반드시 명시하도록 프롬프트 지침 부여.

| 차시 | 강의 및 실습 내용 | 핵심 산출물 |
| :--- | :--- | :--- |
| **1차시** | **웹 데이터 수집 (크롤링 기초)**<br>• 웹사이트 구조(HTML) 파악하기<br>• AI 프롬프트로 [매장명, 주소, 위경도] 수집 코드 생성<br>• 우리 학교 주변 구(區) 데이터부터 전국 단위로 확장 | `starbucks.csv` |
| **2차시** | **인터랙티브 웹 지도 시각화 (OSM 타일 고정)**<br>• API 키 없이 로컬에서 바로 열리는 지도 생성 (`tiles='OpenStreetMap'`)<br>• 마커 클러스터링(MarkerCluster)으로 수천 개 매장 깔끔하게 묶기<br>• 매장 클릭 시 상세 정보 팝업 및 검색 필터 연동 | 브라우저 실행용 `map.html` |

* **실습 프롬프트 예시 (안전성 강화)**:
  > *"수집된 CSV의 위도/경도를 읽어서 Folium 지도를 만들어줘. 별도 API 키 없이 로컬 HTML 파일에서 지도가 100% 정상 출력되도록 `tiles='OpenStreetMap'`을 명시해줘. 마커 클릭 시 매장명과 주소가 카드 형태로 예쁘게 뜨게 해줘."*

* **주요 도구**: Python, Requests/BeautifulSoup, Tkinter, Webbrowser 모듈

| 차시 | 강의 및 실습 내용 | 핵심 산출물 |
| :--- | :--- | :--- |

### [트랙 4] SNS 바이럴형 "대학생 캠퍼스 MBTI / 성향 테스트" 웹앱
* **주제**: "나는 어떤 유형의 대학생일까? 나만의 스낵 MBTI 테스트 만들기"

#### 핵심 학습 논리
* **문법 대신 로직**: 문항별 답변 선택 시 점수 누적(가중치/카운팅 계산)

1. **"나의 캠퍼스 생존 동물 MBTI"** (벼락치기 치타, 과탑 부엉이, 팀플 사자, 미어캣 등)
2. **"조별과제 빌런 vs 수호신 판독기"** (조장 체질, 자료조사 봇, PPT 장인, 프리라이더 등)

| 차시 | 강의 및 실습 내용 | 핵심 산출물 |
| :--- | :--- | :--- |
| **1차시** | **기획 & 점수 로직 설계**<br>• 5~7개 공감형 질문 및 선택지 기획 (A vs B)<br>• 유형별 성향 매핑 로직(E/I, P/J 등) 설계<br>• AI에게 기획안을 전달하여 기본 테스트 진행 구조 작성 | 로직이 담긴 기본 테스트 파일 |
