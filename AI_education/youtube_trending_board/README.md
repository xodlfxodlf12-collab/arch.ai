# 🔥 실시간 유튜브 인급동 랭킹 전광판 (YouTube Trending Board)

대학생 대상 바이브 코딩 및 파이썬 입문(2일 완성)을 위한 유튜브 트렌드 분석 & 데스크톱 툴 프로젝트입니다.

---

## 📁 프로젝트 구조

```
youtube_trending_board/
├── crawler.py       # [1일차] 유튜브 트렌드 데이터 크롤러 (ytInitialData 분석 & CSV 저장)
├── app.py           # [2일차] 유튜브 인급동 랭킹 전광판 데스크톱 앱 (Tkinter + PIL 다크모드)
├── trending.csv     # 크롤링 결과 데이터 (순위, 제목, 채널, 조회수, 썸네일, 링크 등)
├── run.bat          # 윈도우 원클릭 실행 배치 파일
└── README.md        # 실습 가이드 및 안내서
```

---

## 🚀 빠른 시작

### 1. 필수 라이브러리 설치
```bash
pip install requests pillow
```
*(Tkinter, csv, webbrowser, re 등은 파이썬 기본 내장 모듈입니다.)*

### 2. 실행 방법

#### [1일차] 크롤러 실행 (데이터 수집 & CSV 저장)
```bash
python crawler.py
```
- 유튜브의 최신 인기 급상승 동영상을 분석하여 `trending.csv`에 저장하고, 실시간 키워드 TOP 5를 출력합니다.

#### [2일차] 데스크톱 앱 실행 (GUI 전광판)
```bash
python app.py
```
- 멜론 차트 스타일의 세련된 다크모드 위젯 창이 열립니다.

## ✨ 핵심 기능

1. **실시간 멜론 차트 스타일 랭킹 순위표**
   - 1위~3위 강조 배지, 비디오 실제 썸네일 이미지 자동 다운로드 & 캐싱, 제목/채널/조회수/영상 길이 깔끔한 카드 레이아웃.
2. **원클릭 / 더블클릭 즉시 브라우저 재생**
   - 목록에서 영상을 더블클릭하거나 우측 `▶ 재생` 버튼을 누르면 기본 웹 브라우저(크롬 등)가 열리며 영상이 바로 재생됩니다 (`webbrowser.open`).
3. **핫 키워드 전광판 (워드클라우드 태그 TOP 5)**
   - 영상 제목들 중 빈도가 가장 높은 핵심 명사/단어를 상단 전광판에 `#태그` 형태로 표시합니다.
   - 키워드 태그 클릭 시 해당 주제로 즉시 검색이 연결됩니다.
4. **테마별 빠른 선택 칩 버튼 & 실시간 검색**
   - `🔥 인급동 TOP`, `📱 쇼츠 챌린지`, `🎓 대학생 브이로그`, `💻 코딩/IT`, `🎵 인기 음악` 바로가기 지원.
   - 검색창 입력 시 실시간 로컬 필터링 및 엔터 입력 시 유튜브 실시간 수집 연동.
5. **백그라운드 스레드 크롤링**
   - 새로고침 시 UI가 멈추지(Freezing) 않도록 `threading.Thread` 비동기 처리가 적용되어 있습니다.
